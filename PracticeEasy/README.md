# Elementary Python Practice Exercises 🐍

Welcome to my basic problem-solving milestone repository! This folder contains foundational Python scripts designed to practice elementary arithmetic, conditional check gates, string/list parsing loops, and basic algorithmic logic.

## 🛠️ Concepts & Programs Covered

* **`AddTwoNumbers.py`** — Gathering basic user input data and executing simple addition mathematical operations.
* **`Average.py`** — Calculating the mean arithmetic average from a distinct collection dataset.
* **`CountOccurrences.py`** — Iterating through collections or strings to count the occurrences of specific target elements.
* **`EvenOdd.py`** — Implementing the modulus operator (`%`) inside conditional statements to evaluate whether an integer is even or odd.
* **`Largest.py`** — Using logical comparison operators to evaluate multiple inputs and determine the largest numerical value.
* **`ReverseNumber.py`** — Applying mathematical division/modulus extraction loops or slicing methods to reverse integer digits sequence paths.
* **`SumAndAverage.py`** — Processing dynamic data sets to calculate both cumulative sums and arithmetic averages simultaneously.
* **`SumOfDigits.py`** — Deconstructing an integer to iterate over and calculate the sum of its individual constituent numerical digits.


## ⚙️ Core Programming Mechanics Covered
1. **Console Input Parsing**: Utilizing `input()` combined with type casting (like `int()` or `float()`) to safely handle user input data.
2. **Conditional Decision Trees**: Structural implementation of `if`, `elif`, and `else` blocks to create logical validation paths.
3. **Iterative Collection Loops**: Employing `while` loops and mathematical modulus/division tracking to process sequential numbers or items dynamically.
