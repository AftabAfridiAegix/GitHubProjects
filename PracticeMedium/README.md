# Practice Medium

This folder contains intermediate Python exercises focused on list manipulation, nested loops, data deduplication, and search optimizations.

## Files Included
* `FirstRepeatedNumber.py`: A script that takes a sequence of inputs and identifies the very first duplicate value using nested tracking loops.
* `RemoveDuplicates.py`: A script that cleans sequences by extracting and appending unique values to an independent collection.

## Core Concepts Covered
1. **Nested Loop Traversal**: Implementing outer-inner index patterns (`i` and `j`) to compare linear elements against subsequent list items.
2. **Flag Control Mechanisms**: Utilizing nested `break` and loop `else` statements to halt continuous processing the precise moment a duplicate is matched.
3. **Data Deduplication**: Developing conditional lookup checks (`not in`) to safely filter collections and maintain isolated arrays of unique data elements.
