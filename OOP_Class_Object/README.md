# 10. Object-Oriented Programming: Classes and Objects 🐍

Welcome to my tenth Python learning milestone! This repository covers the foundations of **Object-Oriented Programming (OOP)** in Python, focusing on defining classes, initializing instance variables using `__init__`, applying the `self` keyword, and creating custom methods to model real-world objects.

## 🛠️ Concepts & Programs Covered

* **`Class_Object.py`** — Fundamental syntax for defining a blueprint (Class) and instantiating individual user profiles (Objects).
* **`BankAccount.py`** — Simulating state management and logic checks by handling deposits, withdrawals, and tracking real-time ledger updates (`self.balance`).
* **`FinanceTracker.py`** — Building an expense management object array to dynamically append, track, and log microfinance transactional history.
* **`MedicalTracker.py`** — Modeling patient health profiles to monitor diagnostic vitals, logging medical attributes, and generating evaluation summaries.
