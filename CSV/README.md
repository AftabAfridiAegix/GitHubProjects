# 16. CSV Processing 🐍

This repository covers **CSV Data Handling** to store, read, and manipulate tabular data using Python's built-in `csv` module.

## 📁 Files Covered

* **`csv_practice.py`** — Writing and reading rows of structured data using persistent files.
* **`input.py`** — Handling user runtime prompts and feeding data streams into files.

---

## ⚙️ Core Functions

| Function / Method | Purpose |
| :--- | :--- |
| `csv.writer()` | Creates a writer object to write rows to a CSV file. |
| `csv.reader()` | Creates a reader object to loop over lines in a CSV file. |
| `writerow()` | Writes a single row of data to a CSV file. |
| `writerows()` | Writes multiple rows of data at once to a CSV file. |
