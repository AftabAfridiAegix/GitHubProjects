# 12. Object-Oriented Programming: Polymorphism 🐍

Welcome to my twelfth Python learning milestone! This repository covers **Polymorphism**, a core concept of Object-Oriented Programming (OOP) that allows the same method name to execute entirely different actions depending on the object that calls it.

## 🛠️ Concepts & Programs Covered

* **`Polymorphism.py`** — Fundamental implementation using an `Animal` base class and an overriding `Dog` subclass to showcase simple polymorphic method execution.
* **`Medical.py`** — An advanced real-world system utilizing method overriding across a `Doctor` inheritance tree (`Cardiologist` and `Dermatologist`) to dynamically execute specific consultation fee calculations inside an iterable loop object array.
